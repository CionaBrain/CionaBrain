# CionaBrain

CionaBrain is a browser-native TypeScript simulation of the 177-neuron larval
*Ciona intestinalis* CNS. It uses the directed Ryan, Lu & Meinertzhagen (2016)
connectome and runs an independent LIF simulation inside each visitor's Web
Worker. The production server only serves static files; it does not compute
neural state and there is no WebSocket dependency.

## Architecture

```text
src/app.ts              UI, canvas rendering, exports
       ↕ postMessage
src/worker.ts           clock, commands, experiment recording/replay
       ↓
src/simulator.ts        LIF, world, signs, ablation, gains, paths, comparison
       ↓
src/connectome.ts       loads and filters the public Ryan connectome CSV

src/server.ts           small static-file server only
static/dist/            browser bundles generated by esbuild
static/data/            cached public connectome CSV files
tests-ts/               Node tests for the TypeScript simulation core
```

Each tab gets its own Worker, membrane state, random seed, world and experiment
record. Closing the tab destroys that state unless the user exports it.

## Development

Node.js 20 or newer is required. Python is not required.

```bash
npm install
npm run check
npm run build
npm start
```

Open <http://127.0.0.1:8765>. Production uses the same generated static server:

```bash
pm2 start ecosystem.config.cjs --only cionabrain
pm2 save
```

## Data and model assumptions

`data/nodes.csv` and `data/edges.csv` are cached from Netzschleuder's
`cintestinalis` dataset. The graph contains 205 nodes and 2,903 source edges.
Removing 24 peripheral input nodes and four `midtail*` targets leaves the 177 CNS
neurons simulated by the Worker.

- Measured: neuron identities, directed topology, cumulative contact depth, and
  explicit `L`/`R` name suffixes.
- Derived: log-scaled LIF weights, motor laterality score, and touch influence.
- Heuristic: synaptic signs, retinal side proxies, world transduction, movement
  physics, and experimental class-level gain calibration.

Synaptic signs are not fully annotated in the source connectome. The interface
and exports keep measured data separate from model assumptions.

Data citation: Ryan K, Lu Z, Meinertzhagen IA. *The CNS connectome of a tadpole
larva of Ciona intestinalis (L.) highlights sidedness in the brain of a chordate
sibling.* eLife 5:e16962 (2016), CC BY 4.0.
